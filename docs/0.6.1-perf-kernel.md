# JLC 0.6.1 — Full Runtime Takeover / Performance Kernel

> 0.6.0 解决「VM 能不能全面接管」；**0.6.1 解决「全面接管以后，大型项目能不能跑得快、跑得稳、跑得久」**。
> 硬约束不变：纯前端 / GitHub Pages / 零后端 / 零运行时依赖，`.jbc` 仍是静态文件。

## 0. 版本与 ABI：锁死

```js
VERSION = "0.6.1"
BYTECODE_VERSION = 3
ABI_VERSION = "jlc-abi/3"
ACCEPTED_BYTECODE_VERSIONS = [1, 2, 3]
```

0.6.1 **不升级 ABI**。v3 的三个段（`CAPABILITIES` / `RESOURCES` / `FLAGS`）与十一趟验证器一行未动：

```text
0.4 .jbc ─┐
0.5 .jbc ─┼──→ 0.6.1 VM
0.6 .jbc ─┘
```

全部继续跑（`test/kernel06.test.js` 守住）。

## 2. 新增子系统（源码在 `kernel/`，对外仍 `import JLC from "./jlc.js"`）

| 模块 | 计划条目 | 落点 |
| --- | --- | --- |
| `kernel/scheduler-lanes.js` | §2 Scheduler v2.1 | `LaneGovernor`：Priority Aging（有界）+ Lane Quota（`maxConsecutiveSlices`）+ Starvation Guard；接入 `Scheduler.takeTask()` |
| `kernel/frame-budget.js` | §3 Frame Budget | `FrameBudgetManager`：一帧 = 一次 `flush()`，SYSTEM 0.5 / INPUT 1 / INTERACTION 1 / RENDER 3 / EFFECT 1，余量留给 P5–P7；动态截止，不硬切 |
| `kernel/dom-transaction.js` | §4/§5 DOM Transaction + Coalescing | 属性面写（text/attr/class/style/prop）先进 Mutation Buffer，`A.text=1;2;3` 只落 `3`，帧末统一 `commit()`；结构面即时落盘并记账（兄弟链是锚点语义，缓冲会破坏它） |
| `kernel/node-cache.js` | §6/§7 EACH Diff 2 + Keyed Reuse | `KeyedNodeCache`：key 再现 → 复用 scope/DOM/binding/状态；10000 项改 1 项 → 0 新建节点 |
| （Runtime/Effect 内） | §8/§9 Reactive Batch 2.0 + Dep Graph | 事务号计数、effect 去重（`effectDeduped`）、`runtime.dependencyGraph()` / `dependents(name)`：只有依赖路径受影响才跑 |
| （`runtime.profile()`） | §10 Profile 2.0 | `profile.sections`：cpu / dom / scheduler / yield / memory / effects / each / network / resource / faults / hotCache / leaks；0.6 旧字段一个不少 |
| `kernel/hot-cache.js` | §11–§13 Hot Path Cache | Global Lookup Cache（ref → binding 一级直达）、Hot Function Cache；常量池本身已是平铺数组一级直达 |
| （`ResourceKernel`） | §14 Resource Kernel 2.0 | `{ soft, hard }` 双限额：80%（或自定义）先警告，100% 才 `JLCQuotaError`；纯数字 = 0.6 语义 |
| `kernel/memory.js` | §15 Memory Budget | `MemoryAccountant` 分户账：state / checkpoints / tasks / cache / dom / streams / workers；资源 `memory` 派生自账本（KB） |
| `kernel/checkpoint-delta.js` | §16 Checkpoint 2.0 | delta 快照（结构共享）：`cp-N = base(cp-N-1) + 变化部分`；回滚沿链物化；base 被淘汰时依赖者自动升级为完整快照 |
| （`handleFault`） | §17 Fault Recovery 2.0 | 自动升级链 `restart → rollback → degrade`（`FAULT_ESCALATION`），不新增第七级；`faultEscalation: false` 退回 0.6 单级语义 |
| `kernel/leak-detector.js` | §18 Leak Detector | 周期采样 scope/listener/timer/effect/request/task/node；无用户活动的单调增长 → `POSSIBLE_LEAK` → `onWarn` + Profile 展示 |
| （`installResource`） | §19 Network Scheduler | `networkScheduling: true` 时 resource 请求经 P5 NETWORK 车道发起；支持 `networkTimeoutMs` / `networkRetries` |
| （`handle.call`） | §20 Host Call 统一管线 | host call 一律走 `perform` → 调度器，不存在绕过通道；切片开启时返回 Promise |
| （`runtime.vmContext()`） | §21 VM Execution Context | module / machine / scope / state / permissions / resources / scheduler / checkpoint / fault / profiler / domTransaction / cancellation 一帧打包 |
| `kernel/cancellation.js` | §22 Cancellation Kernel | 每任务一个令牌；`handle.cancel(id|label|谓词)`；**scope 销毁级联取消**（组件没了，后台任务不许再动） |

## 3. `runtime: "full"`：统一接管入口（计划 §24/§25）

```js
JLC.mount(source, target, {
  runtime: "full",          // Scheduler/Resource/Permission/Capability/Checkpoint/
                            // Profiler/DOM Transaction/Reactive Batch/Fault Recovery/
                            // Cancellation 全部启用（不是安全绕过，一项不少）
  policy: "open",
  isolation: "strict",
  fault: "restart",
  maxSliceSteps: 20_000,
  frameBudgetMs: 6,
  renderChunk: 64,
  sliceCheckInterval: 512,
  checkpointLimit: 8,
  profile: false,           // 生产环境；开发环境改 true（关闭时保持零开销路径）
  resources: { workers: 4, checkpoints: 8 },
});
```

预设只是默认值：**宿主显式写的每一项都覆盖预设**。未知档位显式报错。
`web/0.6/index.html` 已升级为 **JLC 0.6.1 Runtime Console**，正是按这套默认值挂载。

## 4. 文件结构（计划 §26 的落地形态）

0.6.1 不再把新子系统无脑塞进 `jlc-vm.js`。仓库保持零构建（GitHub Pages 直接跑原生
ESM），`jlc-vm.js` 单向引入 `kernel/`，对外表面不变：

```text
jlc-vm.js          ← Machine / Runtime / Scheduler / DOM_OPS / 验证器（0.6 主体）
kernel/
├── index.js               总出口
├── scheduler-lanes.js     LaneGovernor（配额 / 老化 / 饥饿营救）
├── frame-budget.js        FrameBudgetManager（车道份额 → 动态截止）
├── dom-transaction.js     DomTransaction（Mutation Buffer + Coalescing）
├── node-cache.js          KeyedNodeCache（EACH 复用账）
├── memory.js              MemoryAccountant（分户账）
├── leak-detector.js       LeakDetector（时序采样 → POSSIBLE_LEAK）
├── cancellation.js        CancellationRegistry（令牌 / 级联取消）
├── hot-cache.js           HotPathCache（global / function 直达）
├── dependency-graph.js    依赖图导出 / 可达性查询
└── checkpoint-delta.js    delta 快照 / 链物化 / 淘汰升级
```
